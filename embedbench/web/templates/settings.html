API Key 狀態

API Key 只從環境變數或專案根目錄的 .env 讀取（.env 已在 .gitignore），不會存進資料庫或匯出檔。這裡只顯示「是否已設定」。

匯入舊版 data.db

把舊版 index-*.py 建立的向量匯入，用新的指標重新計算分數，並在排行榜標示「舊資料匯入」。段落以文字比對、問題以 dataset_id（TCEval）或文字比對到新資料集。

快取

向量、reranker 分數與 BM25 索引都會快取在資料目錄，讓中斷的任務可以接續、相同設定不必重算。清除快取不會影響已完成的評測結果。
